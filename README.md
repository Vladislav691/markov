# Решение уравнений с построением графиков

Учебное приложение на C++/CLI и Windows Forms для решения полиномиальных уравнений первой — пятой степени.

Пользователь выбирает степень уравнения, вводит коэффициенты и получает результат вычислений и график функции.

## Возможности

- Решение уравнений от первой до пятой степени.
- Построение графика по введённым коэффициентам.
- Отображение действительных корней на графике.
- Масштабирование и перемещение графика.
- Подстройка интерфейса под размеры окна.

## Методы решения

Для уравнений первой — четвёртой степени используются алгебраические формулы. Для пятой степени применяется численный метод деления отрезка пополам с автоматическим выбором границ поиска.

Численные результаты являются приближёнными. Решение уравнения пятой степени не гарантирует нахождение всех действительных и комплексных корней.

## Технологии

- C++/CLI
- Windows Forms
- .NET Framework
- Visual Studio

## Запуск

1. Скачайте или клонируйте репозиторий.
2. Откройте решение из папки `Project1` в Visual Studio.
3. Убедитесь, что установлены компоненты разработки на C++ и поддержка C++/CLI.
4. Выберите конфигурацию `Debug` и платформу `x64`.
5. Соберите и запустите проект.

## Использование

1. Выберите степень уравнения.
2. Введите коэффициенты, включая нули для отсутствующих слагаемых.
3. Нажмите «Решить».
4. Посмотрите результат и график функции.

Например, для уравнения `x² − 5x + 6 = 0` введите коэффициенты `1`, `-5`, `6`. Корни: `2` и `3`.

## Структура проекта

- `Source.cpp` — точка входа в приложение.
- `MyForm.h` — описание формы и элементов интерфейса.
- `MyForm.cpp` — обработчики событий и взаимодействие с интерфейсом.
- `GraphPanel.h`, `GraphPanel.cpp` — построение графика.
- `LinearEquation.h` — линейные уравнения.
- `QuadraticEquation.h` — квадратные уравнения.
- `CubeEquation.h` — кубические уравнения.
- `QuarticEquation.h` — уравнения четвёртой степени.
- `FifthEquation.h` — уравнения пятой степени.
